# Stock Portfolio Tracker

A beautiful web-based financial dashboard to track your stock mock-investments, built using Python and Streamlit.

## Features
- **Smart Interface**: Uses a simple dropdown menu to instantly add new stocks to your portfolio.
- **Live Computations**: Automatically computes total investments based on the quantity purchased.
- **Visual Analytics**: Automatically displays a bar chart breaking down your portfolio's value by asset.

## How to Run Locally
1. Ensure you have Python installed.
2. Install the requirements: `pip install streamlit pandas`
3. Simply double-click on `start_app.bat` to launch the dashboard!
*(Alternatively, run `streamlit run app.py` from your terminal).*
